# 백테스트 절차

## 원칙
- **미래 데이터를 쓰지 않는다.** 공고 t를 평가할 때는 개찰일이 t보다 앞선 공고만 사용한다.
- 결과가 나빠도 그대로 보고한다. 기대값에 맞추려고 방법을 고치지 않는다.

## 비교 대상 (항상 함께 계산)
1. 항상 0 (사정률 100%)
2. 직전 공고 값 (같은 발주처)
3. 발주처 데이터만 사용한 분포의 최빈 지점
4. 제안 방법 (이론 분포 + 전체 분포 + 발주처 보정)

## 지표
- 적중률: 실제 사정률이 추천 지점 ± 폭 안에 들어온 비율 (폭은 `docs/decisions.md` 기준)
- 평균 절대 오차 (%p)
- 신뢰도 보정: 신뢰도를 구간으로 묶어, 표시한 확률과 실제 적중률이 비슷한지

## 나눠서 보기
- 출처별 (나라장터 / 한전)
- 발주처 건수 구간별 (예: 10건 미만, 10~30, 30 이상)
- 예비가격 범위별 (±2% / ±3%)

## 보고
- 비교 대상 × 지표 표
- 제안 방법이 단순 방법보다 나은지에 대한 한 줄 결론과 근거
- 표본 수가 적어 판단하기 어려운 구간은 명시
- 기준값(예: 보정 기준 30)을 바꿔 비교했다면 각 값의 결과. **어느 값을 쓸지는 사용자가 정한다.**
