# 테스트 케이스

> 개발자가 직접 작성한다. AI는 기대값을 정하지 않는다.
> 기대값이 빈 케이스는 test-writer가 코드로 옮기지 않는다. 소수는 허용 오차를 함께 적는다.

## A. 계산 (src/lib/analysis)

| ID | 대상 | 입력 | 기대 결과 | 허용 오차 |
|---|---|---|---|---|
| TC-A01 | 사정률 표시값 | 기초 100,000,000 / 예정 100,799,800 | [예: 0.7998] | |
| TC-A02 | 분포 집계 | 표시값 [0.80, -0.53, -0.50, ...], 폭 0.25 | [구간별 건수] | |
| TC-A03 | 발주처 비중 | 발주처 10건, k=30 | [예: 0.25] | |
| TC-A04 | 추천 지점 | [분포] | [지점, 확률] | |
| TC-A05 | 이론 분포 재현성 | 같은 seed로 두 번 | 두 결과 동일 | 0 |
| TC-A06 | 데이터 0건 발주처 | 발주처 0건 | [전체 분포만 사용] | |
