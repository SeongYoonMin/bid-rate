# 도메인 정리

> 계산식과 필드 매핑의 기준 문서. 확인된 사실만 적는다. 확인되지 않은 것은 "미확인"으로 둔다.
> 추가·수정은 사용자 확인 후에만 한다.

## 용어

| 용어 | 뜻 | 상태 |
|---|---|---|
| 기초금액 | 발주처가 공고 시 제시하는 기준 금액 | 확인 |
| 복수예비가격 | 기초금액의 ±3% 이내에서 만든 15개 가격 | 확인 (나라장터 실데이터 499/499 ±3% 이내, 2026-10-28) |
| 예정가격 | 복수예비가격 중 입찰자들이 많이 고른 4개의 평균 | 확인 (한전 동일 여부 미확인) |
| 사정률 | 예정가격 ÷ 기초금액. 화면에는 (사정률 − 1) × 100 을 % 로 표시 | 확인 |
| 낙찰하한율 | 공고별로 정해지는 낙찰 가능한 하한 비율 | 값·적용식 미확인 |
| A값 | 적격심사 투찰가 계산에서 하한율 적용 대상에서 빼는 비용 | 적용 여부·방식 미확인 |
| 추정가격 | 부가세 제외 금액 | 한전: 기초금액 ÷ 1.1 확인 |

## 계산식

- 사정률 = 예정가격 ÷ 기초금액
- 화면 표시값(%) = (사정률 − 1) × 100   예: 1.007998 → 0.7998
- 투찰금액: **미확정.** 낙찰하한율, A값 처리 방식을 확인한 뒤 적는다. 그 전에는 구현하지 않는다.

## 출처별 필드 매핑

### 한전 전자입찰 계약정보 API
- 엔드포인트: `https://bigdata.kepco.co.kr/openapi/v1/electContract.do`
- 조회: `noticeBeginDate`, `noticeEndDate` 필수, 최대 90일
- 확인 일자: 2026-10-20 (공고일 2026-08-10~14, 431건, 공사 93건)

| Bid 필드 | 원본 필드 | 비고 |
|---|---|---|

| 공고명 | `name` | |
| 발주기관 | `placeName` | |
| 기관 코드 | `companyId` | 아래 매핑표 참고 |
| 공사 여부 | `itemType` == `Construction` | |
| 낙찰방법 | `bidType` | 적격심사 = `QualifiedEval` |
| 기초금액 | `estimatedPriceBasicAmount` | 공사 93/93 채워짐 |
| 공고일 | `noticeDate` | YYYYMMDD |
| 입찰 종료 | `endDatetime` | |
| 추정가격 | `presumedPrice` | 기초금액 ÷ 1.1 (159/163 = 97.5% 일치, 2026-10-28 확인) |

### 나라장터 낙찰정보서비스
- 엔드포인트: `https://apis.data.go.kr/1230000/as/ScsbidInfoService`
- 확인 일자: 2026-10-28 (API 문서 G2B_API.docx 기반)
- 총 23개 오퍼레이션, 물품/공사/용역/외자 4종 × 기능별

**사정률 계산에 사용할 오퍼레이션:**

`getOpengResultListInfoCnstwkPreparPcDetail` (공사 예비가격상세)

| Bid 필드 | 원본 필드 | 비고 |
|---|---|---|
| 출처 공고번호 | `bidNtceNo` | |
| 공고명 | `bidNtceNm` | |
| 기초금액 | `bssamt` | 99.8% 채워짐 (499/500, 2026-10-28 실데이터 확인) |
| 예정가격 | `plnprc` | 99.8% 채워짐 (동일) |
| 복수예비가격 | `bsisPlnprc` | 1건당 15행, `compnoRsrvtnPrceSno`=1~15 |
| 추첨 여부 | `drwtYn` | Y=4개/공고 (추첨된 4개 평균 → 예정가격) |
| 개찰일시 | `rlOpengDt` | |
| 순공사원가(예정가격 기준) | `PrearngPrcePurcnstcst` | 57.8% 채워짐, 의미 미확인, 사용 보류 |
| 순공사원가(기초금액 기준) | `bssAmtPurcnstcst` | 60.8% 채워짐, 의미 미확인, 사용 보류 |

- 요청 파라미터: `inqryDiv` (1=입력일시, 2=공고번호), `inqryBgnDt`/`inqryEndDt` (YYYYMMDDHHmm), `bidNtceNo`
- 응답 구조: 입찰공고 1건당 15행 (복수예비가격 각 1행). `plnprc`, `bssamt`는 모든 행에 동일 반복.
- 15행 미만 공고(재공고/유찰 등)는 수집 시 제외한다.
- `bidNtceNo` 형식: `ANNAANNNNNNNN` (예: R26BK01642721)
