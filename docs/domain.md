# 도메인 정리

> 계산식과 필드 매핑의 기준 문서. 확인된 사실만 적는다. 확인되지 않은 것은 "미확인"으로 둔다.
> 추가·수정은 사용자 확인 후에만 한다.

## 용어

| 용어 | 뜻 | 상태 |
|---|---|---|
| 기초금액 | 발주처가 공고 시 제시하는 기준 금액 | 확인 |
| 복수예비가격 | 기초금액의 ±3% 이내에서 만든 15개 가격 | 확인 (나라장터 실데이터 499/499 ±3% 이내, 2026-10-28) |
| 예정가격 | 복수예비가격 중 입찰자들이 많이 고른 4개의 평균 | 확인 (한전 동일 여부 미확인) |
| 사정률 | 예정가격 ÷ 기초금액. 화면에는 (사정률 − 1) × 100 을 % 로 표시 | 확인 |
| 낙찰하한율 | 공고별로 정해지는 낙찰 가능한 하한 비율 | 확인 (나라장터 `sucsfbidLwltRate`. 표본 289건: 89.745% 280건, 88.745% 8건, 81.995% 1건, 2026-11-04) |
| A값 | 낙찰하한율 적용 대상에서 빼는 비용의 합. 예정가격의 약 5.24%(중앙값) | 확인 (나라장터 289건, 구성은 아래 "입찰공고정보서비스" 참고. 한전 미확인) |
| 추정가격 | 부가세 제외 금액 | 한전: 기초금액 ÷ 1.1 확인 |

## 계산식

- 사정률 = 예정가격 ÷ 기초금액
- 화면 표시값(%) = (사정률 − 1) × 100   예: 1.007998 → 0.7998
- 낙찰하한가 (A값 있음) = (예정가격 − A값) × 낙찰하한율 + A값
  - 나라장터 공고 289건 모두 실제 개찰 경계("낙찰하한선 미달" 최고액 ~ "정상" 최저액) 안에 들어옴, 원 단위 반올림 ±2원 허용 (2026-11-04)
- 낙찰하한가 (A값 없음) = 예정가격 × 낙찰하한율
  - 미검증: 위 표본에 A값 없는 공고가 없었음. A값 = 0이면 위 식과 같아짐
- 한전 공고에 같은 식이 적용되는지는 미확인
- 투찰금액·투찰 사정률: **미확정.** 정의를 확인한 뒤 적는다. 그 전에는 구현하지 않는다.

### 나라장터 입찰공고정보서비스
- 엔드포인트: `https://apis.data.go.kr/1230000/ad/BidPublicInfoService02`
- 인증키: `.env`의 `G2B_BID_API_KEY` (2026-11-04 기준 `G2B_API_KEY`와 같은 값. 서비스별 활용 승인이 필요하며, 승인 전이나 반영 전에는 "등록되지 않은 서비스키"(코드 30) 오류가 난다)
